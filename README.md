# Qiskit Fall Fest 2026 Phase-1 Architecture Evaluation Report
*Problem Statement Selected:* O3 - Knapsack Optimization Problem  

## 1. Problem Statement Overview
Solving the combinatorial 0/1 Knapsack optimization problem under explicit hardware topology constraints.

## 2. Technical Methodology
The logical circuit was transpiled and executed natively across two distinct topologies using static noise profiles.

## 3. Hardware Topology Analysis & Explanations
*   *Processor A Layout:* Operates using a linear path layout configuration design.
*   *Processor B Layout:* Structured utilizing a custom connected hub geometric configuration mapping.
